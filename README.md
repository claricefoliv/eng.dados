## Sobre o Projeto
O objetivo desta atividade é realizar a extração, processamento e exportação de dados a partir de um arquivo `.csv` contendo informações de discentes de graduação (2026). O sistema foi projetado para:
1. **Ler** os dados do arquivo CSV e mapeá-los para uma estrutura orientada a objetos (Classe `Discente`).
2. **Armazenar** os registros em memória através de uma lista.
3. **Formatar e Imprimir** as informações detalhadas de cada discente.
4. **Exportar** os dados processados para um arquivo texto (`.txt`).
